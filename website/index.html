Private by design

Every path that could leak control has a policy, not a promise.

🔒

Private-server only

ID / relay / public-key are validated together; misconfigured means no connection. Public-rendezvous fallback is compiled out.

🗝️

Password-gated controlling

A device ID alone never dispatches a session. Empty passwords are refused before any handshake starts.

🖥️

Full RustDesk core

Remote control, file transfer, clipboard, multi-display and hardware codecs (VP8/VP9/AV1/H.264/HEVC) — nothing mocked.

🌗

Two real themes

A gradient-glass light skin and a deep-navy night console, following your system with a manual override.

🕓

Honest session history

Local, capped, corruption-tolerant records of what you initiated. “Initiated” never masquerades as “accepted”.

⬆️

Verifiable updates

In-app checks against GitHub Releases; downloads are SHA256-verified before anything on disk is replaced. Fail-closed.

Quick start

From zero to controlling your own machines.

Deploy your server

Run hbbs/hbbr from rustdesk-server on any NAS or VPS.

Install NikoDesk

Grab the release for your platform. On macOS grant Screen Recording & Accessibility when prompted.

Point it at your server

Settings → Private server: ID server, relay, and the server public key.

Connect with a password

Any RustDesk client works as controller — enter the device ID and its password.

Terminal, port forwarding, camera, remote restart, privacy mode and input blocking are deliberately disabled in this product build.
