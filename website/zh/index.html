使用之前

你可能还想知道。

需要自己的服务器吗？
需要可访问的 RustDesk Server OSS 服务，也可使用你已经部署的服务。NikoDesk 未配置私服时不会连接公共注册服务器。
下载更新后会自动安装吗？
目前需要手动安装。下载完成后，按应用中的安装提示退出旧版、替换应用并重新打开；具体步骤与签名说明见发布页。
Android 可以被远程控制吗？
当前 Android 版只作为控制端，连接你的 Windows 或 Mac 电脑，不提供手机被控能力。
和 RustDesk 是什么关系？
NikoDesk 是基于 RustDesk 原生内核的独立开源项目，遵循 AGPL-3.0，与 RustDesk 官方没有从属或背书关系。
